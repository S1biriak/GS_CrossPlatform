# Проверка реализации

Проверено на Windows x64 с установленной Visual Studio 2022 17.14. Дата проверки: 21 октября 2026 года.

- Сборка Release: выполнена без предупреждений.
- Автоматические тесты: 15 из 15 пройдены (6 предметных, 9 интеграционных).
- Проверены: CRUD, 401/403, неверный пароль, испорченный/просроченный JWT, поиск на русском, пагинация, ограничения БД, четыре отчёта и границы периода.
- Проверены конкурентные выдачи одного экземпляра и двух разных экземпляров при одном оставшемся месте лимита.
- Автономная публикация win-x64: выполнена и запущена из отдельного распакованного каталога в режиме Production, без Visual Studio и dotnet run.
- Postman/Newman 6.2.1: два последовательных полных прогона, каждый по 57 HTTP-запросов и 80 assertions; все проверки пройдены.
- Сохранение после перезапуска: создан отдельный экземпляр, процесс сервера остановлен и запущен заново, экземпляр найден с тем же ID и номером, затем удалён.
- Очистка после прогонов подтверждена: 11 книг (включая архив), 5 читателей, 8 выдач. Начальный набор не изменён.
- setup-demo.ps1 проверен в Windows PowerShell 5.1. Скрипты сохранены в UTF-8 с BOM для корректного русского текста в Windows PowerShell.
- Ключи/БД/токены не включаются в Git и распространяемый архив. Полный Newman JSON с ответами хранится только в игнорируемой локальной папке.
- Запуск на Linux/macOS не проверялся; распространяемый архив предназначен для Windows x64.
