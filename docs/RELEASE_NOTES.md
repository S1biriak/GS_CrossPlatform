Первая версия Library API для лабораторной работы по технологиям кроссплатформенной разработки.

- Три предметных класса с бизнес-логикой: Book, Reader, Loan.
- CRUD, выдача/возврат, архивирование книг и блокировка читателей.
- Четыре отчёта с объединением данных через LINQ.
- JWT-вход и роли User/Admin; демонстрация 401 и 403.
- SQLite, миграции, транзакции и защита от двух активных выдач одного экземпляра.
- Swagger/OpenAPI и стабильные маршруты /api/v1 для будущего клиента.
- Подробное руководство для защиты и сценарий демонстрации внутри архива.

Проверено: 15 автоматических тестов; два последовательных прогона Postman/Newman, каждый по 57 запросов и 80 проверок. Подтверждено сохранение данных после перезапуска.

Запуск на Windows x64:

1. Скачать и распаковать LibraryApi-1.0.0-win-x64.zip.
2. Выполнить `powershell -ExecutionPolicy Bypass -File .\start-release.ps1`.
3. Открыть http://localhost:5080/swagger.

Установка .NET и Visual Studio для этого архива не требуется. Для разработки исходников используется Visual Studio 2022 17.14 / .NET 9.

Демонстрационные аккаунты: `admin / Admin-Library-2026!`, `user / User-Library-2026!`. Они предназначены для локальной учебной демонстрации. JWT-ключ создаётся случайно при первом запуске, БД и ключи не включены в архив.

Импортировать оба Postman JSON и выбрать окружение Library API — localhost. Запускать всю коллекцию сверху вниз: токены/ID сохраняются автоматически, тестовые записи очищаются в конце.
